# 🛒 Carrinho de compras

Projeto de estudo desenvolvido com HTML, CSS e JavaScript para
praticar lógica de programação e manipulação de elementos da página.

## Funcionalidades

- Selecionar um produto.
- Informar a quantidade desejada.
- Adicionar produtos ao carrinho.
- Calcular o subtotal de cada item.
- Atualizar o valor total da compra.
- Limpar os produtos e zerar o total.
- Validar a quantidade para aceitar apenas números inteiros positivos.
- Exibir os valores no formato de moeda brasileira.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar

1. Clique em Code e depois em Download ZIP neste repositório.
2. Extraia o arquivo ZIP.
3. Abra o arquivo index.html no navegador.
4. Selecione um produto, informe a quantidade e clique em Adicionar.

Não é necessário instalar dependências.

## Como usar

1. Selecione o produto no campo Produto.
2. Digite uma quantidade inteira maior que zero.
3. Clique em Adicionar.
4. Confira os itens e o valor total no carrinho.
5. Clique em Limpar para começar novamente.

## Aprendizados

Neste projeto, pratiquei:

- Leitura de valores de campos com JavaScript.
- Conversão de textos em números.
- Uso de funções e variáveis.
- Manipulação do DOM.
- Validação de entradas.
- Cálculos e formatação de valores monetários.

## Objetivo

Projeto criado para fins de estudo, sem processamento de
pagamentos ou realização de compras reais.
